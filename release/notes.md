# v3.5.0

## 版本基线

本版本为 yuzaicn fork 的首个发布。代码基线为上游 zyycn/codex-proxy-rs **v3.4.1** 全量，叠加本 fork 自有功能与修复；不包含上游 v3.4.1 之后（v3.5.x–v3.7.x）的变更。

## Fork 功能与修复

以下清单按 `main` 的 PR 合并记录核对；括号内为真实合并提交短 SHA 与 PR 编号。上游 v3.4.1 同步为 PR #17（`0191eb5c`），不重复计入 fork 功能。

- **智能降智检测闭环**：新增检测记录页、配置与 Admin API、并发 Worker、沙箱化 HTML 预览、调度暂停/恢复与健康检查隔离；支持 reasoning effort 的 `auto` 解析、降级重试、失败审计与命中短语，并在轮次中展示恢复数量（`a8e2b71d`/#4、`20468714`/#6、`6e09e437`/#10、`9122d78a`/#14、`9667a015`/#18、`b0aecb3c`/#22、`f0ae0e34`/#23、`1d7b800a`/#25）。
- **重置额度卡检测与消费控制**：增加独立设置、账号范围约束、检测 Worker、自动消费开关、账号表观察列及相关迁移/验收覆盖；普通 HTTP 管理端也可完成重置确认（`42323c30`/#2、`c3d8d9a1`/#21、`d5e9360e`）。
- **凭据导入与账号生命周期可靠性**：账号重导入保留设置；支持逐行导入重试、部分成功与稳定失败码；全失败不发布快照；防止导入文本保留凭据；风险/未知结果不再自动重试；记录安全的刷新诊断并区分 OAuth 429/5xx 重试语义；轮换时保留 refresh token，并以回归测试守护上游导入重试契约（`1131e81d`/#3、`9f5f01c6`/#5、`e0120975`/#7、`835a3f88`/#8、`1cb8f769`/#13、`36079870`/#16、`7b873da0`/#15、`de109649`/#20、`50d1307b`/#31）。
- **OpenAI 请求失败边界修复**：将 Astra `unsupported_value` 400 判为终态，避免跨账号重试风暴；识别 WebSocket close 1008 且零事件的换号路径并修正调度健康度归因（`63518399`/#27、`78d816e5`/#28）。
- **安全与构建基础设施**：升级 rustls 至 0.23.45 以修复 RUSTSEC-2026-0285；加固容器缓存与 main 分支检查（`6504054a`/#29、`ae87b03e`/#24）。
- **仓库与发布目标迁移**：将发布工作流、Compose、README 及功能性仓库引用统一指向 `yuzaicn` fork（`464c2376`/#1、`272b5a70`/#32、`3cd7cc72`/#33）。
